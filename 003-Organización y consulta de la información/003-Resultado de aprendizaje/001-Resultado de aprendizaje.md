##Resultado de aprendizaje 3

Realiza operaciones de gestión, consulta y análisis de la información siguiendo las especificaciones de diseño y utilizando las herramientas proporcionadas por los sistemas ERP-CRM.

##Criterios de evaluación

a) Se han utilizado herramientas y lenguajes de consulta y manipulación de datos proporcionados por los sistemas ERP-CRM.

	Hemos visto cómo podemos utilizar SQL para consultar y modificar los datos de nuestro ERP-CRM. También hemos trabajado con PHP y SQLite para poder acceder a la base de datos y mostrar la información mediante JavaScript, lo cual nos permitió seguir desarrollando nuestro proyecto.

b) Se han generado formularios.

	Hemos visto diferentes formas de crear formularios utilizando HTML y JavaScript, empezando por formularios sencillos hasta llegar a formularios que se generan automáticamente según los campos de nuestra base de datos. Esto me dio una idea de cómo podría implementar esta funcionalidad en mi CRM, para no tener que crear cada formulario manualmente.

c) Se han generado informes.

	Hemos visto cómo podemos generar informes a partir de los datos de nuestro ERP-CRM, pudiendo ordenar, filtrar y realizar cálculos con la información de las tablas. También hemos trabajado con gráficas para poder representar los datos de una forma más visual, lo cual me parece interesante para implementarlo en mi CRM.

d) Se han exportado datos e informes.

	Hemos visto diferentes formatos para exportar datos como CSV, HTML, Markdown y Excel. En los ejercicios trabajamos principalmente con CSV, aprendiendo a generar archivos con PHP y a exportar los datos de nuestra base de datos. También añadimos a DarkOrange la posibilidad de exportar las tablas y los informes a CSV, pudiendo descargar únicamente los datos que tenemos filtrados.

e) Se han automatizado las extracciones de datos mediante procesos.

	Hemos visto cómo podemos utilizar PHP para extraer los datos de una base de datos SQLite y guardarlos en un archivo CSV. También hemos trabajado con Python y cron en Linux, lo cual nos permitió ver cómo podemos automatizar procesos, como guardar el uso del procesador y de la memoria RAM en un archivo sin tener que hacerlo manualmente.

f) Se ha verificado el rendimiento del sistema ERP-CRM.

	Hemos visto diferentes herramientas para comprobar el rendimiento de nuestro sistema, como htop en Linux. También hemos trabajado con Python utilizando la librería psutil para obtener información sobre el consumo de CPU y RAM, guardando los datos en un CSV y creando gráficas para poder ver cómo cambia el consumo de recursos.

g) Se han documentado las operaciones realizadas y las incidencias observadas.

	Hemos visto la importancia de documentar los cambios que realizamos en nuestro ERP-CRM, utilizando archivos Markdown para guardar información sobre el proyecto. También hemos comparado diferentes versiones de DarkOrange, como la 021 y la 022, pudiendo ver las diferencias entre sus funcionalidades y los cambios que se realizaron. Esto me permitió ver la importancia de llevar un registro de las modificaciones para poder detectar posibles problemas.

h) Se ha obtenido información relevante a partir de los datos procesados.

	Hemos visto cómo podemos aprovechar los datos de nuestro ERP-CRM para obtener información mediante tablas, filtros y gráficas. También hemos trabajado con un dashboard y un apartado de Reporting, lo cual me dio ideas para mi propio CRM, ya que quiero que los usuarios puedan ver estadísticas de sus clientes y tener un resumen de la información más importante.
