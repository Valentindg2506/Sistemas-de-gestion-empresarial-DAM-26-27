EL AVANCE DE ESTA UNIDAD

Una primera base.
Funciones concretas.

El proyecto llega hasta la gestión de registros. Cada entidad utiliza la misma API y los formularios se construyen desde las columnas de la base de datos.

01 / REGISTROS

Consultar y actualizar

Crear, consultar, editar y eliminar registros de las siete entidades del modelo aeronáutico de clase.

LA ESTRUCTURA DE CLASE

Una pieza para cada tarea.

HTML, CSS y JavaScript en el cliente; PHP y SQLite en el servidor. Sin frameworks, con funciones sencillas y comentarios en español.

01 / CLIENTE

La interfaz

HTML y CSS presentan las tablas y los formularios. JavaScript envía las peticiones con fetch.

↓
02 / API

Las operaciones

PHP organiza las rutas con switch y devuelve las respuestas en JSON.

↓
03 / DATOS

La persistencia

SQLite conserva los registros, los tipos de las columnas y las relaciones del modelo.

PUESTA EN MARCHA

Abre tu espacio
de gestión.

La entrega incluye una base preparada con datos ficticios. El instalador permite crear tablas propias escribiendo el modelo de texto de clase.

Abrir el instalador ↗
  1. 01

    Comprueba PHP

    Necesitas la extensión SQLite3 habilitada.

  2. 02

    Arranca el proyecto

    Abre una terminal en la carpeta DarkGoldenRod:

    php -S localhost:8000
  3. 03

    Selecciona una entidad

    Entra en localhost:8000 y empieza a gestionar sus registros.
