Resultado de aprendizaje
Identifica sistemas de planificación de recursos empresariales y de gestión de relaciones con clientes (ERP-CRM) reconociendo sus características y verificando la configuración del sistema informático.

Criterios de evaluación

a) Se han reconocido los diferentes sistemas ERP-CRM que existen en el mercado.
	Hemos visto una serie de sistemas ERP-CRM lo cual me dio una idea de que sistema elegir para mi proyecto, todos son intersantes y cubren diferentes necesidades. Pero en mi 
	caso me decidi por el CRM (Customer Relationship Management). Ya que quiero un programa en el cual los usuario puedan llevar un control de sus clientes.

b) Se han identificado los diferentes tipos de licencia de los sistemas ERP-CRM.
	Hemos visto muchos tipos de licencias como GPL, Propietaria o Apache, en mi caso para mi proyecto de un CRM elegi una licencia propietaria, para poder a futuro vender el 
	acceso a la plataforma mediante una suscripcion.
	
c) Se han comparado sistemas ERP-CRM en función de sus características y requisitos.
	Hemos visto una serie de sistemas ERP-CRM lo que me permitio darme ejemplos y ideas para poder crear mi proyecto de la proxima unidad, pudiendo ver las competebncias
	y las funciones indispensables para el mismo.
	
d) Se ha identificado el sistema operativo adecuado a cada sistema ERP- CRM.
	Hemos visto que para nuestro proyecto podemos utilizar una arquitectura web, haciendo que el cliente pueda acceder desde un navegador web compatible con Windows, Mac y Linux. Para el 
	servidor utilizaremos Linux con una arquitectura LAMP, utilizando Linux, Apache, MySQL y PHP.
	
e) Se ha identificado el sistema gestor de datos adecuado a cada sistema ERP-CRM.
	Hemos visto diferentes sistemas gestores de bases de datos, principalmente bases de datos relacionales como SQL, MySQL y PostgreSQL, además de bases de datos documentales como MongoDB. 
	En mi caso para el proyecto CRM elegí MySQL, ya que vamos a trabajar con PHP y Laravel en el servidor.
	
f) Se han verificado las configuraciones del sistema operativo y del gestor de datos para garantizar la funcionalidad del ERP-CRM.
	

g) Se han documentado las operaciones realizadas.


h) Se han documentado las incidencias producidas durante el proceso.
